# 🚀 Mizukiranere - Developer Portfolio

A sleek, responsive, and modern personal developer portfolio built with semantic HTML5, modern CSS3 (Glassmorphism & Neon Dark Theme), and Vanilla JavaScript.

## ✨ Features
- 🎨 **Modern Dark Aesthetic**: Glassmorphism cards with smooth gradients and hover interactions.
- 📱 **Fully Responsive**: Mobile-first design that adapts seamlessly from phones to desktops.
- ⚡ **Lightweight & Blazing Fast**: Zero heavy framework dependencies, clean Vanilla JS.
- 🛠️ **Showcase Sections**: About, Categorized Tech Stack & Skills, Featured Projects, and Direct Contact.
- 🌐 **Ready for GitHub Pages**: Can be published online with a single click.

## 🚀 How to Enable GitHub Pages (Free Hosting)
1. Go to repository **Settings** on GitHub: `https://github.com/Mizukiranere/portfolio/settings/pages`
2. Under **Build and deployment > Source**, choose `Deploy from a branch`.
3. Select branch: `main` and folder: `/ (root)`.
4. Click **Save**.
5. Your website will be live in seconds at: `https://Mizukiranere.github.io/portfolio/`
